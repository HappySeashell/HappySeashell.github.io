## 学术资源查找

### 搜索引擎

#### 百度学术

对于中文文献的支持较好，配合 MyLOFT 可实现无缝查询。

https://xueshu.baidu.com/

{% blogCard https://xueshu.baidu.com/ target:_self rel:nofollow %}
#### 必应学术
界面清爽，若无梯子，用其查找英文文献较方便，但文献来源较少。

https://cn.bing.com/academic

{% blogCard https://cn.bing.com/academic target:_self rel:nofollow %}
#### 谷歌学术
当下最好用的学术搜索引擎，但没有条件正常访问。百度可得国内镜像网站。

https://scholar.google.com.hk/


{% blogCard https://scholar.google.com.hk/ target:_self rel:nofollow %}
#### OALIB

OALIB 是Open Access Library（开放存取资源图书馆）的简称。该站点收录了大部分免费下载的文献。

https://www.oalib.com

{% blogCard https://www.oalib.com target:_self rel:nofollow %}
### Sci-Hub
只要提供完整的 URL 或 DOI，就能免费下载到pdf格式的文献。搜索前最好通过微软或谷歌学术获取DOI。

https://www.sci-hub.ren/

{% blogCard https://www.sci-hub.ren/ target:_self rel:nofollow %}
### Z-Library
可以按名称、作者、期刊、DOI、MD5搜索，并进行全文搜索（中文亦可），但收录得不如 Sci-Hub 全。

https://zh.booksc.me/

{% blogCard https://zh.booksc.me/ target:_self rel:nofollow %}
### 中国国家图书馆博士论文库
收录了大量国内名校博士论文，具有极大参考价值。

https://read.nlc.cn/allSearch/searchList?searchType=65&showType=1&pageNo=1

{% blogCard https://read.nlc.cn/allSearch/searchList?searchType=65&showType=1&pageNo=1 target:_self rel:nofollow %}
## 书籍资源查找

### 书享家

一个很全面的站点资源导航。

https://shuxiangjia.cn/

{% blogCard https://shuxiangjia.cn/ target:_self rel:nofollow %}
### Z-Library
可以按名称、作者、ISBN、出版社、MD5搜索，并可选择电子书格式。收录的书籍非常全面，想找的基本都能找到，也可以进行全文搜索，并且可以进行在线格式转换。

https://zh.sa1lib.org

{% blogCard https://zh.sa1lib.org target:_self rel:nofollow %}
### 鸠摩搜索

曾经是书籍搜索的不二之选，现在因为资源较少、广告增多而落为下乘。

https://www.jiumodiary.com/

{% blogCard https://www.jiumodiary.com/ target:_self rel:nofollow %}
### LoreFree

未登录时每天三个下载额度，登录后每天五个额度。资源不如 Z-Library 全，多为中文书籍。

https://ebook2.lorefree.com/

{% blogCard https://ebook2.lorefree.com/ target:_self rel:nofollow %}
### 淘链客

优势在于可以搜到 Github 上的资源，但一部分资源需要购买积分下载。

https://www.toplinks.cc/

{% blogCard https://www.toplinks.cc/ target:_self rel:nofollow %}
### 书山有路

一个个人站点，现已停更，但书目数量仍非常可观。

https://www.ssylu.com/

{% blogCard https://www.ssylu.com/ target:_self rel:nofollow %}
### 点点文档

资源来自网盘，良莠不齐。敏感词语无法搜索。

https://www.junengfan.cn/bd

{% blogCard https://www.junengfan.cn/bd target:_self rel:nofollow %}
### 爱下电子书

擅长搜网文小说，较纯净，无广告。
大陆版：

https://www.aixdzs.com/

{% blogCard https://www.aixdzs.com/ target:_self rel:nofollow %}
台版：（无法下载，但可阅读）

https://tw.ixdzs.com/

{% blogCard https://tw.ixdzs.com/ target:_self rel:nofollow %}
## 影视资源查找

### 可乐资源

集合了美、英、韩剧及各种电影资源，纯净无广告。

https://kelemeiju.kuaizhan.com/

{% blogCard https://kelemeiju.kuaizhan.com/ target:_self rel:nofollow %}
### 樱花动漫
有大量动漫资源，但有广告且画质不清晰。

https://www.imomoe.live/

{% blogCard https://www.imomoe.live/ target:_self rel:nofollow %}
## 网盘资源查找

### 罗马盘搜索

搜索不限次数，但要登录且关注广告公众号。搜索结果很全面，但模糊搜索极其难用。

https://www.luomapan.com/

{% blogCard https://www.luomapan.com/ target:_self rel:nofollow %}
